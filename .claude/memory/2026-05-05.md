# 2026-05-05 — Pre-Generation Validation 観測事例の正式化

## コンテキスト

Yahoo ニュース記事 (Anthropic Claude Mythos / kyegomez OpenMythos) の事実確認から始まった雑談セッションが、最終的に semantic-ci-code の §23.1 入力 contract「engine は state の出自を問わない」を **設計記述から repo 内で実行可能な再現テストに格上げ** する成果に発展した。

3 段階の実験(`vfr_vs_ifr` → `run_matrix` → `run_pregen`)を `/tmp/openmythos-experiment/` で展開し、最後の pre-generation validation を docs + 自己完結 reproduction として PR #34 で正式取り込み。bot review 対応で reproducibility まで担保。

## 設計判断

- **bot review への対応強度**: chatgpt-codex-connector が「再現スクリプトが repo 外にあると検証不能」 を指摘。トーンダウン (Option B: 観測ノートに reframe) ではなく **self-contained 化** (Option A: 合成 baseline `tinypkg` を新設) を選択。理由: 実験は本来決定論的で再現可能性に意味があり、トーンダウンは情報損失を伴う
- **`experiments/` 新設の判断**: 観測事例のスクリプト・データの正式な置き場所として top-level に新カテゴリを設置。`docs/` (markdown のみ) でも `tests/` (pytest 対象) でもない。`multi_agent_audit_case.md` の系譜に運用パターンを敷く
- **README に doc を追加しない**: 既存 precedent (`multi_agent_audit_case.md` / `brief_*_planning.md` も README には載っていない) に従う。CLAUDE.md docs テーブルへの追記のみ
- **OpenMythos pilot を出典セクションに保持**: 当初の OpenMythos での pilot は完全削除せず、provenance として「より大きな外部コードベース上でも同じ性質が成立した」記録を残す

## 成功パターン

- **「/tmp 隔離 → 重要な部分だけ self-contained 化して repo」 の 2 段プロセス**: 探索段階は外部依存ありで広く試し、正式取り込み時に最小再現に絞り込む。OpenMythos の 1086 行 → tinypkg の 25 行に圧縮しても性質は変わらず再現できた
- **比喩を実験で実証する pipeline**: VFR/IFR / コンパス / 計器飛行のアナロジーが、5 ケース matrix と 3 ケース pre-gen で **数値として裏付けられた**。今後は修辞ではなく実測値として説明できる
- **3 段階の実験で価値主張を階層化**: ① 単一ケース(VFR vs IFR の生 diff 比較) → ② 5 ケース matrix(intent 直交性) → ③ pre-gen 3 ケース(virtual state contract)。それぞれが独立した主張を担い、累積的に value proposition を補強
- **bot review を「正しいか」「重いか」で評価**: 指摘の妥当性とコストを user と一緒に分けて議論し、対応強度を判断。bot を単に従う / 単に却下する以外の運用ができた

## 修正・訂正

- **「コード変更の問題に限れば」 と射程を矮小化した誤読**: user に「セマンティック CI は仮想コードでも動くしコードであることを前提としていない」と訂正された。§23.2 を読み直して「`(intent, stateA, stateB)` を表現できる任意ドメインで動く」 と修正
- **YAML パースエラー (intent 文字列内のコロン)**: `run_matrix.py` 初回実行で `intent: refactor: rename...` がパース失敗。intent をダブルクォートで囲んで対応
- **`ruff format --check` を走らせ忘れ**: ローカルで `ruff check` だけ通して push、CI #92 が format ステップで exit 1。`ruff format` 適用で対応 (commit `e7d42a6`)。今後は push 前に format も走らせる

## メモ

- VFR/IFR / コンパス / 計器飛行 の比喩は壁打ちでも実験でも一貫して機能した。今後の説明にも転用できる強い metaphor stock
- bot review が reproducibility の弱さまで指摘してきたのは貴重。**人間レビュアより厳格な性質** (主張と実装の整合) を捉えてくれる
- 「演繹的開発 vs 帰納的開発」 のフレーミング (user 提示) が、この一連の実験を理論的に統一した。design.md に inline する価値あり (§23 補遺 or 新セクション候補)
- 「**proprioception primitive for AI agents**」 という positioning は、semantic-ci を「コード変更検証ツール」 から「agentic AI infrastructure」 へ昇格させる有力な語彙。memory 系・検索系と並ぶ第 3 primitive として説明できる
- OpenMythos 解析の副産物として「Open<X> シリーズの存在意義」 を社会学的に整理した議論は、design ドキュメントに馴染まないが face value として記録に残す価値あり
