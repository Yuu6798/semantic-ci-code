## 設計判断

1. **提案の精査で P1/P2/D1 が既に実装済みと指摘**: user の 5 提案のうち
   「feature なのに追加制約なし警告」「bugfix なのに test 制約なし警告」は
   detect_p1 / detect_p2 として hazards.py に既存。intent 内容ベース推論は
   scope guard ("not an intent validator") 違反のリスクで却下

2. **PR 順序の矛盾を v2 で修正**: v1 では PR-B 先行だったが、I1 メッセージに
   `--intent` を含めるため PR-A 先行に反転。user レビューで指摘された通り

3. **--package-root without --doctor を usage error に変更**: v1 ではサイレント
   無視だったが、user 指摘の通り「沈黙を減らす思想」と合わないため exit 2 に変更

4. **package_root 解決の共有化**: target_doctor.py の _resolve_package_root() を
   doctor_support.py に抽出、init --doctor と target-doctor で共有。挙動のズレを
   構造的に防止

5. **ADVISORY-I1 は scope guard に抵触しない判定**: intent の内容解析ではなく
   空かどうかの構造チェック。P1/P2 が制約の有無を構造的に検出するのと同じレイヤー
