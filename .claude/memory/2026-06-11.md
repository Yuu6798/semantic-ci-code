  lockfile → audit input 翻訳は `name==version` pin では済まず、**resolution
  semantics が spec 本体**だった: chat APPROVE (初回 commit `3d0ea86`) 後、
  merge までに **follow-up 17 commit** — PEP 508 marker operators / wildcard
  version marker / PEP 440 prerelease 順序 / dev・optional group 除外 / uv
  requested extras closure / uv resolution markers / lock variants 区別 /
  local package skip / `pylock.*.toml` named variant 発見 / pylock × 旧
  pip-audit (--locked 非対応) の fail-closed 化。各 fix は test encode 済み
  (commit 単位で test 追加) なので §5.4 の encoding 要件自体は充足。
