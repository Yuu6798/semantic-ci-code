## 学んだ pattern

### Wheel packaging で `__file__` parent walk は壊れる

- editable install では動くが、`pip wheel` 後の通常 install では `config/` が wheel に入らず FileNotFoundError
- 対応: package data 配下に置く + `importlib.resources.files(pkg).joinpath(name)` + `as_file()` で path を取り出す
- `[tool.setuptools.package-data]` に拡張子パターンを追加するのを忘れない

### Module scope の compound 文を見落としがち

- `if`/`try`/`for`/`while`/`with`/`match` の body は module scope に効く
- function/class body は別スコープ
- `ast.TryStar` (Python 3.11+) は `ast.Try` と別ノード型で、isinstance check に明示的に含める必要がある

### Effect detector の "保守的" の方向

- 一般に detector の保守的 = false positive 寄り (effect を取り逃さない)
- shadowing の場合: annotation-only `op: int` は shadow 扱いしない方が保守的 (検出 chance を残す)
- 多言語 DB の language filter: foreign signature を採用しない方が precision を保てる
