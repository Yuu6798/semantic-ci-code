## 設計メモ: B = coverage advisory (次に実装する自分 / Codex への 0-round 鉱脈)

D6 (nested-function vacuous PASS) を起点に、 vacuous PASS 一般 (D4/D6 class) への
構造的対処として **coverage advisory** を蒸留した。実装はしていないが、 以下を
そのまま planning brief に落とせる粒度で残す。

### 問題の正体

verdict は決定論 (入力に対し無損失) だが、 入力の CodeState は実コードの **lossy
な射影**。情報損失は全部「抽出・射影」段に溜まる。D6 = 「intent が気にする領域」と
「射影がカバーする領域」がズレ、 drift が実在する所の外で PASS してしまう状態
(= 再現可能に間違える / deterministic ≠ correct)。

### 3 択と結論

- **A 捨てる** (射程外と定義): 沈黙の vacuous PASS = 罠。境界が契約に見えてないと
  利用者を裏切る。**silent A は禁止**、 必ず B に格上げ。
- **B 漏れを宣言・委譲** (本命): extractor を厚くせず「この変更領域を射影がどれだけ
  カバーできたか」を出す。**個別ハザード検出ではなく観測カバレッジの自己監査**なので
  イタチごっこを抜け、 未知の未知 (D8…) も同じ網で拾う。「継ぎ目の検査」の最も
  きれいな形。
- **C LLM ジャッジを部品化** (コア不可侵): B の宣言した穴の背後に挿す pluggable な
  provider の一実装。安全性は **膜 (advisory は verdict に不参加、 §23.3)** に
  全依存。膜が漏れたら決定論を毒す。ジャッジ自身は un-certified (亀の上の亀) なので
  「助言止まりで grace degradation」が唯一の安全担保。

→ **B (汎用カバレッジ宣言形) を背骨、 C を背後の pluggable provider、 A は文書化
された撤退としてのみ**。B と C は競合でなく protocol と provider の関係 (SSP の
sensor adapter 構図と同型)。

### 実務設計 (狼少年を殺す)

- **絶対に exit code を変えない** (`severity: info` / Advisor チャネル)。
  ブロッキング化した瞬間に CI から外される。
- **交差フィルタ**で鳴らす対象を「**未測定領域 ∩ PASS した制約**」に限定。vacuous
  PASS が隠れ得るのはそこだけ。これで発火率が桁で落ち、 残った警告が全部「本当に
  怪しい場所」になる (= 狼少年 killer)。
- **粒度**: (ii) verdict 全体ロールアップ 1 行を先に → (i) hunk 単位注記は後で。
  (i) は「diff hunk → AST → 測定次元」の帰属という **新しい継ぎ目**を飲む必要が
  あるので、 需要確認後。
- coverage 信号は **それ自体決定論的** (純関数) なので run 間で flap しない =
  flaky CI にならない。LLM ジャッジ (C) と違う利点。

### 閾値・較正

- 統計は 2 仕事: **(1) 需要 GO/NO-GO** (安い (ii) で「皆気にするか」検証) → **(2)
  閾値較正**。較正は **gaming 耐性の高い事後・敵対信号** (dogfood の "coverage-low
  が実際に vacuous PASS だった率") で引く。ループ内の発火率は gaming できるので
  物差しにしない。
- **非定常**: 4.7→4.8 で分布がズレる = 閾値は賞味期限つき。定数でなく**保守する
  setpoint**。ii→i は直線でなく螺旋 ((i) の精度 ↑ → 較正データ質 ↑ → 次の精度 ↑)。

### 通底するメタ原理 (今日の壁打ち全体の結論)

> **検証不能な真値を、検証可能な保守的代理で置き換える。盲点とマージンを飲んで
> 監査可能性を買う。**

これが verdict (lossy CodeState)・外部化 budget (保守的 cap)・閾値 (frozen
setpoint)・決定論境界 (非決定論を authoring に検疫) で **フラクタルに反復**。関連
派生則: ①検査コストは消えず継ぎ目へ移転する (保存則。semantic-ci の D5/D6 は射影/
operator の継ぎ目で起き、 再利用部品 AST/CC 自体は無傷)、②再利用 = 償却済み信頼の
輸入、③semantic-ci の決定論は製造でなく再利用部品からの**継承**。
